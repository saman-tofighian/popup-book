# سفرِ کاغذی — کتابِ پاپ‌آپِ سه‌بعدی (Next.js + React Three Fiber)

کتابی راست‌به‌چپ با ۴ صحنه‌ی پاپ‌آپ (جنگل شبانه، شهر، دریا، فضا). ورق‌ها واقعاً خم می‌شن و برمی‌گردن،
و لایه‌های کاغذی با باز شدن کتاب از حالت تخت بلند می‌شن (با سایه‌ی واقعی بین لایه‌ها).

```bash
npm install
npm run dev      # http://localhost:3000
npm run build && npm start
```

- ورق‌زدن: دکمه‌ها، کلیدهای ← → ، کلیک روی دسته‌ی صفحه‌ها، یا (روی گوشی) سوایپ روی کارتِ متن.
- متن‌ها و اسم خودت: `config/book.js` (بخش `TEXTS` و `AUTHOR`).
- صحنه‌ها: `components/canvas/scenes/` — هر لایه یه `<Paper>` است (شکل‌ها در `lib/shapes.js`).
- بدون API و بدون کلید؛ فونت وزیرمتن داخل پروژه‌ست. انتشار: Vercel یا هر هاست Node.
